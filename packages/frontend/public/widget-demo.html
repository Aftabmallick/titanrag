TitanRAG Chat Widget Demo

This page demonstrates the <titan-chat> custom element. All styling is isolated inside the Shadow DOM so host CSS cannot corrupt it.

Embed Code:

<!-- 1. Include the 15KB lightweight bundle -->
<script src="/widget.js" async></script>

<!-- 2. Drop the custom element anywhere on your page -->
<titan-chat
  workspace="default"
  api-key="tr_demo_key"
  base-url="http://localhost:8000"
  theme="dark"
  position="bottom-right"
  bot-name="Titan AI"
></titan-chat>

Look at the bottom-right corner of your screen to interact with the widget!
